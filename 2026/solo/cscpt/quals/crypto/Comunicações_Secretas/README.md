# Comunicações Secretas

**Category** : Crypto
**Points** : 500

Em tempo de mundial não podemos arriscar que as mensagens de apoio ao nosso capitão sejam interceptadas pelos agentes disruptivos de outras nações. No CSCPT ajudámos a desenvolver o sistema de mensagens mais seguro para enviar pequenas mensagens de apoio ao nosso capitão. Ninguém nos vai parar!
