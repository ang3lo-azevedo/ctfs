# Hidden in Plain Stream

**Category** : Forensics
**Points** : 500

A workstation was imaged after a "system maintenance helper" script was found running. The script is still on the disk, along with an encrypted file it produced. Recover the secret.

**WARNING:** The disk image contains a functional malicious script. Although its effects are scoped to a specific file in a specific directory, **never execute any artefact from this challenge on your host system**. Any dynamic analysis must be performed inside a disposable sandbox with no sensitive or critical files. Treat this as you would real ransomware. **ONLY** run it in a controlled, throwaway environment. You have been warned!
